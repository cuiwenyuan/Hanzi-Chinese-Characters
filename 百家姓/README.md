# 百家姓

《百家姓》是中国古代蒙学经典"三百千"之一，与《三字经》《千字文》并称，是一部关于中文姓氏的启蒙读物。本文件提供《百家姓》的简体版与繁体版，均带汉语拼音，格式参考《三字经》风格。

## 简介

《百家姓》集中收录了中华常见的姓氏，以四言韵语写成，朗朗上口，便于儿童诵读记认。它与《三字经》《千字文》共同构成传统蒙学的基础读物，统称"三百千"。

## 作者与起源

- **成书年代**：北宋初年（约公元 10 世纪）
- **作者**：佚名（旧传为北宋初年儒生所作，具体作者已不可考）
- **开篇缘由**：因宋代皇帝姓赵，故"赵"姓列于首位；"钱"为吴越国国王钱镠之姓，"孙"为钱镠正妃之姓，"李"为南唐国姓，依次排列，反映了当时的政治格局。

## 历史背景

《百家姓》并非按姓氏人口多寡排列，而是兼顾韵律和谐与当时政治、社会地位。其成书背景与北宋初年吴越归宋、南北一统的历史进程密切相关。此后历经元、明、清各代增补，形成多种版本，但通行诵读本基本定型于宋代原编。

## 内容概述

本版按通行诵读本整理，共收录 **486 个姓氏**：

| 类别 | 数量         | 说明                           |
| -- | ---------- | ---------------------------- |
| 单姓 | 408 个      | 每字为一个姓氏，每 4 字为一组             |
| 复姓 | 78 个（39 组） | 每 2 字为一个复姓，每 4 字为一组（含 2 个复姓） |

- **编排形式**：全文以四言韵语写成，单姓部分每 4 字一组、复姓部分每 4 字一组（2 个复姓）；
- **排列顺序**：以"赵钱孙李"开篇，单姓在前、复姓在后；
- **复姓示例**：万俟、上官、夏侯、诸葛、闻人、东方、赫连、皇甫、尉迟、公羊等。

## 文化意义

- 集中体现了中国悠久的姓氏文化与宗族观念；
- 是研究中国姓氏源流、人口迁徙与家族史的重要基础资料；
- 反映了传统社会"尊祖敬宗"的价值取向；
- 至今仍是华人社会认知本族姓氏、开展寻根问祖活动的基础文本。

### 格式说明

参考《三字经》风格：每 4 字为一组（短语），其后紧跟该组拼音；每两组为一行，空格分隔。

示例（简体）：

```
赵钱孙李 zhào qián sūn lǐ  周吴郑王 zhōu wú zhèng wáng
万俟司马 mò qí sī mǎ  上官欧阳 shàng guān ōu yáng
```

### 数据说明

- 拼音由 `pypinyin` 生成，并对照姓氏特殊读音校正；
- 复姓拼音直接给出，含多音节特殊读法（如 万俟 mò qí、尉迟 yù chí、淳于 chún yú、单于 chán yú）；
- 常见多音字作姓氏时的特殊读法已校正，例如：仇 qiú、单 shàn、解 xiè、查 zhā、盖 gài、乐 yuè、缪 miào、华 huà、燕 yān、任 rén、那 nā、都 dū 等；
- 繁体版由 `opencc`（s2t）转换汉字得到，拼音保持一致（个别复姓如"万俟"依专有名词规则保留传统写法）。

## 注意事项

- 本整理版供学习与个人研究使用；
- 《百家姓》不同历史版本所收姓氏数量略有出入（常见说法为约 500 余姓），本版采用通行诵读本，共 486 个姓氏；
- 复姓中的"万俟"等在传统排印中存在"万俟 / 萬俟"两种写法，本版依转换工具专有名词规则作"万俟"。
