# 千字文

《千字文》是中国古代蒙学经典"三百千"（**《三字经》《百家姓》《千字文》**）之一，由南北朝时期梁朝散骑侍郎、给事中 **周兴嗣** 编纂。全文四字一句、两句一韵，通篇对仗工整、文采斐然，既是识字习文的启蒙读物，也是书法与文学的典范之作。

## 文档内容

- **全文 250 句，1000 字**（相传一千字无一重复）
- **带拼音**：每个四字短语后紧跟该组拼音（含声调符号）
- **简体版 / 繁体版** 各一份，内容一一对应

| 文件           | 说明                    |
| ------------ | --------------------- |
| `千字文_简体版.md` | 简体汉字 + 拼音             |
| `千字文_繁体版.md` | 繁体汉字 + 拼音（汉字转繁体，拼音不变） |

## 文档特点

- 采用 **Markdown 短语-拼音格式**，与《三字经》《百家姓》风格一致
- 每 4 字为一组，其后紧跟该组拼音；每两组为一行，空格分隔
- 示例：`天地玄黄 tiān dì xuán huáng  宇宙洪荒 yǔ zhòu hóng huāng`
- 全文按内容分为四段，便于诵读与讲解

## 分段说明

1. **天地开篇**：叙天地开辟、四时运行、物产万物与人文政教
2. **修身立德**：论身体发肤、修身养性、伦理纲常与道德品节
3. **都城宫室**：写都城宫阙、典籍功臣、封赏地理与九州风物
4. **农事结语**：述农事为本、自省慎独、生活百工与全文收束

## 作者与成书

- **作者**：周兴嗣（？—521），字思纂，南朝梁文学家
- **成书年代**：梁武帝时期（约 6 世纪初）
- **成书典故**：相传梁武帝命人从王羲之书法中拓取一千个互不重复的字，交周兴嗣连缀成韵文；周兴嗣一夜之间缀集成篇，鬓发皆白，遂成千古名篇。

## 内容概述

《千字文》以一千个汉字勾勒出一幅宏大的知识画卷，内容涵盖：

- **天文地理**：天地、日月、星辰、四时、寒暑、山川、物产
- **人物历史**：三皇五帝、尧舜禹汤、周秦汉唐等历代兴衰
- **伦理修身**：孝悌、忠信、仁爱、谦谨、慎独等道德规范
- **典章制度**：都城宫室、典籍文物、职官封赏
- **农事生活**：农耕、饮食、起居、百工技艺
- **结语**：以"谓语助者，焉哉乎也"收束全篇

## 文化意义

- 与《三字经》《百家姓》并称"三百千"，是古代儿童识字启蒙的核心教材
- 是"三百千"中**成书最早、且唯一确切可知作者与成书年代**的一部
- 通篇押韵、对仗工整，兼具文学、书法、识字多重价值，影响远及东亚汉字文化圈
- 一千字包罗天文、地理、历史、伦理、教育等诸多方面，被誉为"微型百科全书"

## 数据说明

- 正文依据维基文库《千字文》（周兴嗣 撰）标准简体文本整理，共 250 句 / 1000 字
- 拼音由 `pypinyin` 生成，并对文中特殊读音做了校正：
  - 调（律吕**调**阳）→ tiáo
  - 宿（辰**宿**列张）→ xiù（星宿）
  - 裳（乃服衣**裳**）→ cháng
  - 重（菜**重**芥姜）→ zhòng（看重）
  - 的（渠荷**的**历）→ dì（的历：明亮）
  - 属（**属**耳垣墙）→ zhǔ（倾耳注意）
  - 稽（**稽**颡再拜）→ qǐ
  - 说（**说**感武丁）→ yuè（傅说，人名）
- 繁体版汉字由 `opencc`（`OpenCC('s2t')`）转换，拼音保持原读音不变

## 使用方式

- 直接打开 `千字文_简体版.md` 或 `千字文_繁体版.md` 阅读、诵读
- 如需重新生成，确保已安装 `pypinyin`、`opencc-python-reimplemented`，在 `千字文/` 目录下运行：
  ```bash
  python 生成千字文.py
  ```
